# THE WOOSYUME COMPANY

Independent Mac and iPhone app portfolio. The complete static website is in `docs/`. Open `docs/index.html` directly to preview it.

## GitHub Pages

In **Settings → Pages → Build and deployment**, select **Deploy from a branch**, **main**, and **/docs**. The project site uses relative links and needs no build step.

## Editing the draft

- The homepage is `docs/index.html`, the catalog is `docs/products/index.html`, and each app has its own `docs/products/<app>/index.html`.
- The developer portrait, personal comment, and conference decks are in `docs/about/index.html`.
- When FingerPad is ready, update its development status on the home, catalog, and detail pages, and add its official links to its detail page.
- Shared presentation styles and images are in `docs/assets/`.
